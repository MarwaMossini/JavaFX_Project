# Employee Management System

A Java application designed in Spring 2026 for the Asian University for Women (AUW), developed as an Object-Oriented Programming group project.

## Features
- Add, view, search, update, and delete employees.
- Organize employees by department.
- Calculate salaries and generate payslips.
- View employee statistics and print reports.
- Save and load employee records.

## Technologies
Java, JavaFX, and CSS.

## How to Run
1. Download and extract `EmployeeManagementSystem.zip`.
2. Import the project into Eclipse.
3. Configure the JavaFX SDK and run `MainApp.java`.

For the console version, run `Main.java`.

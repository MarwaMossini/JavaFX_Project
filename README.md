# Employee Management System

An academic employee management application with a JavaFX interface and a console version. The project covers employee records, departments, salary calculations, and payslips.

## Academic Context
- Course: Object-Oriented Programming (CSCI2002), Asian University for Women (AUW).
- Semester: Summer 2026.
- Team: Two students.
- Report submitted: 22 August 2026.

## My Contribution
I developed the JavaFX interface, wrote Java code, and tested the application's features and interface behavior.

## Features
- Add, view, search, update, and delete employees.
- Organize employees by department.
- Calculate salaries and generate payslips.
- View employee statistics and print reports.
- Save and load employee records.

## Technologies
Java, JavaFX, and CSS.

## How to Run
1. Download and extract `EmployeeManagementSystem.zip`.
2. Import the project into Eclipse.
3. Configure the JavaFX SDK and run `MainApp.java`.

For the console version, run `Main.java`.
